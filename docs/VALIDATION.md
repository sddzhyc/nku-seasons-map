# 第一阶段验收记录

日期：2026-10-23。数据为当日实际获取的 OSM 快照，非模拟 POI。

## 已通过

- TypeScript 检查及 Vite 正式构建。
- 4 项数据测试：校园范围相交筛选、分号多物种及名称搜索、不完整上游数据拒绝、真实银杏多边形和多多边形成员去重。
- 在实际浏览器中搜索“银杏”，列表仅剩匹配物种；选择后地图只有 10 处银杏要素高亮。
- 点击指定树林标记，弹窗展示 `species=银杏`、`leaf_cycle=deciduous` 等标签，原始链接正确指向 `way/1448582302`。
- 无结果搜索提示、清空搜索、全部物种恢复、说明弹窗开关。
- 标准 OSM 底图测试时 24 张当前视图瓦片均成功载入，可切回本地校园简图。
- 390 × 844 手机视口检查、回到校园全景、物种列表排版；页面没有横向溢出，测试后已恢复默认桌面视口。
- 正式构建产物的本地预览可正常交互，未发现浏览器脚本错误。
- 手动在线同步超时后，网页显示“同步暂不可用 · 已保留上次有效数据”，按钮恢复可点击，原地图及 31 个要素保留。
- 依赖审计为 0 个已知漏洞。osmtogeojson 的旧 XML 解析依赖已通过 overrides 更新。

## 外部限制与阶段边界

- 本机脚本访问公共 Overpass 时实际遇到 HTTP 406/429；浏览器请求也出现超时。本次未验证成功的在线同步，不应以失败保护验证替代同步成功证据。
- 物候日历、当前秋叶阶段、后台持久化的物种索引、Actions 自动更新和 github.io 部署尚未实现，按约定留待第一阶段检查后推进。
- 校园简图是发布时快照，不会因物种查询成功而自动重新生成。重新初始化可运行 `npm run data:bootstrap`。
